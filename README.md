# Stock Market Analytics and Prediction Dashboard

This project is a Business Analytics portfolio project that retrieves, stores, analyses, visualises, and predicts US stock market performance.

## Current Phase

Phase 1: Historical stock data collection.

## Stocks Used

- Apple (AAPL)
- Microsoft (MSFT)
- NVIDIA (NVDA)

## Technologies

- Python
- pandas
- NumPy
- yfinance
- Matplotlib
- Plotly
- Scikit-learn
- SQL Server
- Streamlit
